# Органайзер рецептов

Учебный проект по разработке требований к программному обеспечению.

## Описание

«Органайзер рецептов» — приложение для ведения личной кулинарной книги и базы рецептов:

*   первых блюд;
*   вторых блюд;
*   десертов и выпечки;
*   напитков.

Пользователь может добавлять новые рецепты, просматривать их, редактировать, удалять, выполнять поиск и фильтрацию по категории блюда или ингредиентам.

## Цель проекта

Разработать требования к приложению и представить их в виде технического задания и отдельных задач GitHub Issues.

## Документация

Основное техническое задание находится в разделе Wiki данного репозитория.
